# Site VO3 Chips

Site oficial para divulgação e consulta dos resultados de provas cronometradas pela VO3 Chips.

## Organização dos resultados

- `resultados/pdf/`: resultados históricos em PDF.
- `resultados/csv/`: arquivos CSV das provas recentes.
- `data/provas.json`: catálogo exibido e pesquisado na página inicial.

O site é estático e publicado automaticamente pelo GitHub Pages.
